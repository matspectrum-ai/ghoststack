# GhostStack — Diretrizes para Agentes

## Líder absoluto: gstack

O gstack é a única interface de trabalho deste projeto.
Nenhum agente ou ferramenta pode executar código, design ou deploy fora do pipeline gstack.

## Pipeline obrigatório

/office-hours → /autoplan → /ship

## Regras

- Todo trabalho deve ser iniciado por /office-hours ou /autoplan
- Nenhuma alteração no código sem PLAN.md aprovado
- Nenhum deploy sem /ship
- Nenhum commit direto; usar /ship

## Quando o gstack estiver ativo

Defina o propósito do projeto, stack e próximas fases exclusivamente via skills gstack.
Se o gstack perguntar algo, responda em ptBR.
